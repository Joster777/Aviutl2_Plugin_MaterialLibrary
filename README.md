# 汎用素材 (MaterialLibrary) - AviUtl ExEdit2 汎用プラグイン

効果音・BGM・画像・動画などの素材を専用のフォルダに置いておき、
**設定画面のドロップダウンから選ぶだけで使える** ようにするプラグインです。

毎回ファイルを探してドラッグする手間をなくし、よく使う素材をすばやく呼び出せます。

## 特長

- 素材を **種類(フォルダ)ごとに整理** して、ドロップダウンから選べる
- 選んだ素材の形式(音声・画像・動画)に合わせて、**オブジェクトが自動で切り替わる**
  - タイムライン上の色も、音声=赤 / 画像=青 / 動画=青赤グラデーションになります
- 素材を選ぶと、**オブジェクトの長さを素材の長さに合わせ**、オブジェクト名を素材のファイル名にする
- 編集メニューから、**再生バーの位置にオブジェクトを生成** できる(ショートカットキーの割り当ても可能)
- 素材の登録は、ファイルを選ぶか、**ファイルをドラッグ&ドロップ** するだけ

## 動作環境

- AviUtl ExEdit2(バージョン○○以上)
- Windows 10 / 11

## 導入方法

1. [Releases](../../releases) ページから、最新版の zip をダウンロードします。
2. zip を解凍し、`MaterialLibrary.aux2` を AviUtl ExEdit2 のプラグインフォルダにコピーします。
3. AviUtl ExEdit2 を起動(再起動)します。

初回の起動時に、素材を置くフォルダが自動で作られます。

## 素材の置き場所

素材は、AviUtl2 の **アプリケーションデータフォルダ** の中にある `MaterialLibrary` フォルダに置きます。

```
(アプリケーションデータフォルダ)/MaterialLibrary/
├─ SE/        効果音
├─ BGM/       BGM
├─ Image/     画像
└─ (好きな名前のフォルダ)/
```

- 初回起動時に、`SE`、`BGM`、`Image` の3つのフォルダが作られます。
- **直下のフォルダ名が「種類」** としてドロップダウンに表示されます。好きな名前のフォルダを追加できます。
- 種類のフォルダの中に、さらにフォルダを作って整理しても使えます。
- **素材の一覧は、AviUtl2 の起動時に読み込まれます。** ファイルを手動で追加したときは、AviUtl2 を再起動してください。

### 対応している形式

| 種類 | 拡張子 |
|---|---|
| 音声 | wav, mp3, ogg, flac, m4a, aac, wma, opus |
| 画像 | png, jpg, jpeg, bmp, gif, webp, tga |
| 動画 | mp4, mov, avi, mkv, webm, wmv, flv, m4v, mpg, mpeg, mts, m2ts |

## 使い方

### 素材を使う

1. 追加メニューから **「汎用素材」** を追加します。
   (または、編集メニューの「**汎用素材を再生バーの位置に生成**」を実行します)
2. 設定画面で **「種類」** を選びます。その種類の素材だけが表示されます。
3. **素材** を選びます。
   オブジェクトの長さと名前が素材に合わせて変わり、形式に合った色に切り替わります。

新しく作ったオブジェクトは「(未選択)」の状態で、種類と素材を選ぶまで何も読み込みません。

### 設定項目

| 項目 | 内容 |
|---|---|
| 音量 | 0 〜 200 |
| 左右 | -100 〜 100 |
| 再生位置 | 素材のどの位置から再生するか(秒) |
| ループ再生 | オンにすると、素材の長さより長く引き延ばして繰り返す |
| 長さを素材に合わせる | オブジェクトの長さを素材の長さに戻す |

音声・動画は、**ループ再生がオンのとき以外は、素材本来の長さより長く引き延ばせません。**

### 素材を登録する

**方法1: 設定画面から**
1. オブジェクト設定画面の「素材の登録」を開きます。
2. 「登録するファイル」で、登録したいファイルを選びます。
3. 「ライブラリに登録」ボタンを押します。

**方法2: ドラッグ&ドロップ**
プレビュー画面などにファイルをドラッグ&ドロップしたときの取り込み先として「素材ライブラリに登録」が表示されます。

### 編集メニュー(ショートカットキーを割り当て可能)

- 汎用素材を再生バーの位置に生成
- 汎用素材の長さを素材に合わせる

## 注意事項

- 素材ファイルは **同梱されていません**。ご自身で用意した素材を置いてください。素材の利用規約・著作権は、各自でご確認ください。
- 音声の再生で、**音の高さや長さがずれる** 場合は、ソースコードの `MATERIAL_LIBRARY_HOST_RESAMPLES` の値を切り替えてビルドし直すと改善することがあります。
- 実行前に、プロジェクトの保存(バックアップ)をおすすめします。
- 本プラグインを使用したことによる、いかなる損害についても責任を負いません。

再現手順や、使用している AviUtl ExEdit2 のバージョンも書いていただけると助かります。
